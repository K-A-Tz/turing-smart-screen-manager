# Установка — Русский

## 1. Проверка USB
Подключите экран и выполните `lsusb`, `ls -l /dev/serial/by-id/`. Проверенная модель имеет USB ID `1a86:5722` и идентификатор `usb-Turing_UsbMonitor_USB35INCHIPSV2-if00`. Номер `ttyACM0` может меняться.

## 2. Установка менеджера
```bash
git clone https://github.com/K-A-Tz/turing-smart-screen-manager.git
cd turing-smart-screen-manager
chmod +x *.sh
mkdir -p ~/bin
cp *.sh ~/bin/
~/bin/turing-manager.sh
```

## 3. Установка программы
Выберите в меню **2** для проверки и скачивания официального проекта, затем **1** для проверки Python, создания `~/.venv` и установки зависимостей, затем **3** для прав и **9** для USB. Исправления требуют подтверждения. После добавления в `dialout` выйдите и войдите в Linux снова.

## 4. Настройка COM-порта
Откройте `~/turing-smart-screen-python/config.yaml` через пункт **7**. В существующей секции `config:` укажите с двумя пробелами отступа:
```yaml
  COM_PORT: "/dev/serial/by-id/usb-Turing_UsbMonitor_USB35INCHIPSV2-if00"
```
Не добавляйте вторую секцию `config:`. Перед редактированием создаётся `config.yaml.backup`.

## 5. Управление
**4** — запуск; **5** — остановка; **6** — конфигуратор тем (сначала остановите экран); **8** — список тем; **10/11** — включение/отключение автозапуска; **12** — журнал. Запуск дисплея может занять 10–20 секунд. Не запускайте две копии одновременно.

## 6. Автозапуск
Скрипт `~/bin/start-turing.sh` ждёт USB до 60 секунд. Выберите пункт **10**, затем перезайдите в графический сеанс. Для ручного запуска: `~/bin/turing-manager.sh`.
